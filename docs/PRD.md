# 智能化认知诊断系统 MVP — PRD

## 1. 项目背景

在「AI+教育」场景下，准确评估学生的知识掌握程度（认知诊断）是实现个性化推荐和智能体辅导的基础。

## 2. 核心功能

- **知识点掌握诊断**：基于 IRT/DINA 模型，计算学生在各知识点上的掌握概率
- **知识图谱展示**：可视化展示知识点之间的前置/后续关系
- **学习建议生成**：基于诊断结果，生成个性化学习建议（LLM 加分项）

## 3. 用户故事

- 作为学生，我想查看自己在各知识点上的掌握程度，以便了解薄弱环节
- 作为老师，我想快速定位班级的共性问题，以便调整教学重点

## 4. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 后端 | Python 3 + FastAPI | 轻量、异步、自带文档 |
| 算法 | numpy | 矩阵运算高效 |
| 存储 | SQLite | 零配置，适合 MVP |
| 前端 | 原生 HTML + Chart.js | 无构建，CDN 引入 |
| LLM | DeepSeek | 成本低、中文能力强 |

## 5. 数据规模

- 5 个知识点：分数加法、分数减法、分数乘法、分数除法、分数混合运算
- 20 道题目，每道题关联 1-3 个知识点
- 10 名学生的作答记录
